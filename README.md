# 🌟 네웹 ➡️ AniList 만화 트래커 (`nw_anilist`)

> **네이버 웹툰 감상 기록을 대표 애니/만화 트래킹 플랫폼인 AniList에 스마트하게 동기화하는 브라우저 확장 프로그램 (Manifest V3)**

---

## ✨ 핵심 기능

1. **원클릭 일괄 동기화 (Batch Sync)**:
   - PC 웹 브라우저뿐만 아니라 **스마트폰 '네이버 웹툰 앱'에서 본 최근 감상 기록까지** 네이버 계정(마이페이지)에서 한 번에 스캔하여 AniList로 싹 업데이트합니다.
   - 내가 원할 때 버튼 한 번으로 동기화하므로, 실시간 백그라운드 상시 감시 부담 없이 편안하게 이용할 수 있습니다.
2. **진도율(Diff) 스마트 비교 & 프리뷰**:
   - `AniList 현재 진도`와 `네이버 최근 본 회차`를 실시간 대조하여 변경된 회차(예: `142화 ➡️ 145화 (+3화)`)를 시각적으로 확인하고 반영할 수 있습니다.
3. **완결작 & 휴재작 자동 완독(`COMPLETED`) 처리**:
   - 네이버에서 **'완결'**된 웹툰은 AniList 상태를 자동으로 **`COMPLETED(다 읽음)`**으로 등록합니다.
   - **'휴재'** 중인 웹툰 역시 나온 최신화까지 깔끔하게 다 읽음 처리할 수 있는 전용 토글 옵션을 지원합니다.
4. **한글 제목 검색 & 1클릭 매칭**:
   - 한국어 웹툰명으로 AniList의 원제(`native`) 및 영문명을 지능형 검색하여 자동 연결합니다.
   - 검색 결과 포스터를 확인하며 1초 만에 직접 매칭하거나 변경할 수 있습니다.
5. **PC 웹 뷰어 실시간 스크롤 감지 (선택 사항)**:
   - PC 브라우저로 웹툰을 볼 때는 화면 하단에 미니멀 플로팅 배지가 나타나며, 80% 이상 스크롤 시 자동으로 회차가 기록됩니다.

## 🚀 설치 및 사용 방법

### 1. 브라우저에 확장 프로그램 등록 (Chrome / Naver Whale / Edge)
1. 크롬 또는 웨일 브라우저 주소창에 다음 주소를 입력합니다:
   - **Chrome**: `chrome://extensions`
   - **Naver Whale**: `whale://extensions`
2. 우측 상단의 **[개발자 모드]** 스위치를 켭니다.
3. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭합니다.
4. 본 프로젝트 폴더(`c:\Users\BBB\Desktop\me\nw_anilist`)를 선택합니다.
5. 브라우저 툴바에 **'네웹 ➡️ AniList 트래커'** 아이콘이 등록됩니다!

### 2. AniList 계정 연결 (최초 1회)
1. 툴바의 확장 프로그램 아이콘을 클릭합니다.
2. 상단 **[AniList 연동]** 또는 안내 배너의 **[1. 토큰 발급 페이지 열기]**를 클릭합니다.
3. AniList 승인 창에서 `[Authorize]`를 누르고, 생성된 토큰을 복사하여 입력창에 붙여넣고 **[연결 완료]**를 누릅니다.
4. 프로필 사진과 유저명이 뜨면 영구적으로 로그인 상태가 유지됩니다.

### 3. 네이버 최근 본 웹툰 동기화
1. 네이버에 로그인되어 있는 상태에서 팝업창의 **[⚡ 네이버 최근 본 웹툰 스캔]** 버튼을 누릅니다.
2. 최근 본 웹툰 목록과 AniList 진도 차이가 한눈에 표시됩니다.
3. 아직 연결되지 않은 웹툰은 **[+ 작품 연결]**을 눌러 AniList 작품을 선택합니다 (포스터 미리보기 지원).
4. 하단의 **[🚀 선택한 X개 웹툰 AniList에 일괄 동기화]**를 누르면 완료됩니다!
